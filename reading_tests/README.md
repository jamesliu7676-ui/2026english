# 短篇閱讀測驗題庫

此資料夾用來存放英文短篇閱讀測驗。每篇建議包含：

- 主題
- 來源
- 字數
- 閱讀短文
- 題目
- 答案
- 解析

## 建議檔名

使用流水號管理，例如：

- `reading_001.md`
- `reading_002.md`
- `reading_003.md`

若要讓頁面自動抽題，請同步更新：

- `question_bank.json`
- `quiz.html`
- `collection_log.md`
- `replenishment_plan.md`

## 來源標記

每篇都要清楚標示來源類型：

- `自編`
- `公開資料改寫`
- `新聞或文章改寫`
- `AI 輔助生成，人工校對`

若不是自編內容，請保留原始來源名稱、網址與查閱日期。

## 優先題型

題目設計優先採用下列題型：

- 主旨題
- 細節題
- 推論題
- 字彙題
- 代名詞指涉題
- 句意理解題
- 段落排序
- 多文本整合題
- 圖表閱讀題
- 混合題：選擇 + 簡答

## 頁面更新與重複率

`quiz.html` 會讀取 `question_bank.json`，每次開啟頁面或按「更新題目」時重新抽題。

重複率控制原則：

- 同一次測驗不重複同一題。
- 瀏覽器記錄最近出過的題目。
- 題庫足夠時，優先避開最近出過的題目。
- 目標：本次題目重複率低於 5%。

若題庫題數不足，頁面仍會出題，但應繼續擴充題庫。
