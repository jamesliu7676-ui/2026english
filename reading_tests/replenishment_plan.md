# 題庫補題計劃

## 目標

將短篇閱讀測驗題庫擴充到 200 題以上，並維持低重複率、來源可追蹤、題型分布穩定。

目前基準：

- 已建立題庫：`question_bank.json`
- 已建立更新頁面：`quiz.html`
- 目標題數：200 題以上
- 目前策略：每週新增 5 篇閱讀文本，每篇 8 題，約 40 題

## 補題節奏

| 頻率 | 工作內容 | 預期產出 |
|---|---|---:|
| 每週 | 補一批正式題庫 | 5 篇、約 40 題 |
| 每月 | 題庫品質盤點 | 題型比例、來源比例、重複率檢查 |
| 臨時 | 有合適素材時補充時事題 | 1-2 篇主題題 |

## 每週補題規格

每篇閱讀文本建議 180-260 字，搭配 8 題：

| 題型 | 每篇題數 |
|---|---:|
| 主旨題 | 1 |
| 細節題 | 1 |
| 推論題 | 1 |
| 字彙題 | 1 |
| 代名詞指涉題 | 1 |
| 句意理解題 | 1 |
| 多文本／圖表／段落排序 | 1 |
| 混合題：選擇 + 簡答 | 1 |

## 主題輪替

| 週次 | 主題重點 | 題型重點 |
|---|---|---|
| 第 1 週 | 校園、公告、生活、健康、旅遊 | 穩定基本題型 |
| 第 2 週 | 科普、環境、交通、社區、消費 | 增加圖表與多文本 |
| 第 3 週 | 文化、人物、科技、公共資訊 | 增加推論與句意理解 |
| 第 4 週 | 混合文本、表格、訊息、短公告 | 接近學測混合題型 |

## 時事題補充規則

時事題可以增加新事務、新事件、關鍵字與趣味性，但必須遵守以下規則：

- 優先選擇教育、科技、環境、文化、生活、健康、交通、公共政策等適合學生閱讀的主題。
- 不直接複製新聞原文；只能摘要、改寫或自編。
- 每篇保留來源名稱、網址、查閱日期與使用方式。
- 若事件仍在發展中，題目避免問尚未穩定的結論。
- 避免高度爭議、血腥、災難細節、政治立場導向或不適合學生的內容。
- 題幹可加入新關鍵字，例如 AI tools、electric buses、climate action、museum exhibition、sports event、digital tickets。

## 時事題來源建議

| 來源類型 | 用途 | 使用方式 |
|---|---|---|
| 官方公告 | 公共資訊、交通、教育政策、展覽活動 | 改寫成公告或多文本題 |
| 教育與科普網站 | 科技、環境、健康、文化 | 改寫成短文與字彙題 |
| 英語學習新聞 | 慢速英文、國際新知 | 參考主題，自編短文 |
| 博物館、圖書館、活動網站 | 展覽、活動、文化資訊 | 改寫成訊息題、圖表題 |

## 每批完成檢查

每次補題後需確認：

- `question_bank.json` JSON 格式正確。
- 新增題目 ID 不重複。
- 同篇內題目不重複。
- 題型覆蓋符合每週規格。
- `collection_log.md` 已記錄新增篇數、題數、來源與主題。
- 若加入時事題，已標註來源網址與查閱日期。
- 題庫總題數已更新。
